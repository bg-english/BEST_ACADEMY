# BEST Academy - Gamified English Learning App

A gamified English learning platform for BEST Academy students built with Next.js and Supabase.

## Features
- Gamified learning with XP, badges, and streaks
- Real-time teacher dashboard
- Performance tracking by skill area (vocabulary, grammar, listening, speaking, writing)
- 4 units covering A1.3 English curriculum

## Tech Stack
- Next.js 14 (App Router)
- Supabase (Database + Realtime)
- TypeScript
- Tailwind CSS

## Setup
```
npm install
cp .env.example .env.local
npm run dev
```
